# Contributing — Student Guidelines

Thank you for helping keep **Diploma in Artificial Intelligence** accurate and useful.

## ✅ You are welcome to
- **Report a problem** (typo, broken link, unclear instruction, failing code) by opening an **Issue** with the file name and what is wrong.
- **Suggest a resource** (article, video, dataset) by opening an Issue with the link and why it helps.
- Ask questions in class or by email at **aseefahmed@aptechnorth.edu.pk**.

## 🚫 Please do not
- Submit assignment or project **solutions** to this repository (no pull requests with your answers).
- Commit secrets, passwords, API keys, personal data or large files.
- Copy material from this repository into paid or commercial content (see the CC BY-NC 4.0 [LICENSE](./LICENSE)).


## 🔧 Small fixes via pull request
1. Fork the repository and create a branch: `git checkout -b fix/short-description`.
2. Make a focused change (one fix per pull request).
3. Write a clear commit message, e.g. `Fix broken link in labs/README.md`.
4. Open a pull request explaining the change. The instructor reviews and merges at their discretion.

## 🤝 Code of conduct
Be respectful, helpful and honest. Academic integrity rules in the [README](./README.md) apply to everything you post here.
