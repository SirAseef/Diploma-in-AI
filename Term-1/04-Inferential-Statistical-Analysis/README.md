**Term 1 — Data Science Foundations** · Module 04

> Original teaching notes by Aseef Ahmed. Session titles follow the programme syllabus; all explanations, code and exercises are written independently and are **not** official Aptech courseware.

## 🎯 Learning outcomes

By the end of this module you will be able to:

- Describe data with summary statistics
- Apply the rules of probability
- Measure relationships with correlation and regression
- Draw conclusions about populations using samples, tests and ANOVA
