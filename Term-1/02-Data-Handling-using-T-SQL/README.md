# Data Handling using T-SQL

**Term 1 — Data Science Foundations** · Module 02

> Original teaching notes by Aseef Ahmed. Session titles follow the programme syllabus; all explanations, code and exercises are written independently and are **not** official Aptech courseware.

## 🎯 Learning outcomes

By the end of this module you will be able to:

- Explain how relational databases and SQL Server store data
- Write T-SQL queries using filters, sorting, grouping and conditional logic
- Combine data from several tables with joins, unions and subqueries
- Insert, update and delete data safely
- Use built-in string, date, math and aggregate functions
