# Data Science with Python

**Term 1 — Data Science Foundations** · Module 03

> Original teaching notes by Aseef Ahmed. Session titles follow the programme syllabus; all explanations, code and exercises are written independently and are **not** official Aptech courseware.

## 🎯 Learning outcomes

By the end of this module you will be able to:

- Manipulate arrays and tables with NumPy and Pandas
- Import data from files and MongoDB and clean it
- Visualise data with Matplotlib and Seaborn
- Build and evaluate regression, classification, clustering and association models
