# Managing Large Datasets using MongoDB

**Term 1 — Data Science Foundations** · Module 05

> Original teaching notes by Aseef Ahmed. Session titles follow the programme syllabus; all explanations, code and exercises are written independently and are **not** official Aptech courseware.

## 🎯 Learning outcomes

By the end of this module you will be able to:

- Model and store documents in MongoDB
- Query with operators and aggregation pipelines
- Speed up queries with indexes; scale with replication and sharding
- Use transactions, MongoDB tools, Atlas (cloud) and PyMongo
