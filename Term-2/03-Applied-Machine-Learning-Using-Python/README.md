## 🎯 Learning outcomes

By the end of this module you will be able to:

- Run end-to-end ML projects: EDA, preprocessing, modelling, evaluation
- Handle imbalanced and time-series data
- Use ensembles, AutoML and reinforcement learning
- Deploy models responsibly and run A/B tests
