# Fundamentals of Computer Vision

**Term 2 — Artificial Intelligence** · Module 05

> Original teaching notes by Aseef Ahmed. Session titles follow the programme syllabus; all explanations, code and exercises are written independently and are **not** official Aptech courseware.

## 🎯 Learning outcomes

By the end of this module you will be able to:

- Preprocess images and understand how they are formed
- Detect, segment and track objects
- Recognise faces and extract features
- Use generative models and depth perception
