# Deep Learning using Neural Networks

**Term 2 — Artificial Intelligence** · Module 04

> Original teaching notes by Aseef Ahmed. Session titles follow the programme syllabus; all explanations, code and exercises are written independently and are **not** official Aptech courseware.

## 🎯 Learning outcomes

By the end of this module you will be able to:

- Explain how neural networks learn
- Build and tune networks in TensorFlow/Keras
- Apply CNNs to images and RNNs to sequences
- Generate data with VAEs, GANs and style transfer
